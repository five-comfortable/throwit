  - 타겟 사용자 분석 3그룹 (일반 시민, 이사/청소 업체, 재활용 관심 사용자)

  - 핵심 기능 명세서 6개 (F1~F6) 상세 정의
    - F1: 수수료 조회 (입력/출력/처리로직/예외처리)
    - F2: 온라인 배출 신청 4단계 (입력검증/상태흐름/신청번호 형식)
    - F3: 마이페이지 (취소 가능 조건 정의)
    - F4: 재활용 역경매 (상태 흐름 AVAILABLE→RESERVED→SOLD)
    - F5: 오프라인 배출 안내 4카테고리
    - F6: 사용자 인증 (인증/비인증 기능 구분)
  - 사용자 흐름(User Flow) 5개 정의
    - 수수료 조회 흐름 (API 호출 포함)
    - 온라인 배출 신청 흐름 (4단계 ProgressBar)
    - 재활용 역경매 흐름
    - 오프라인 배출 안내 흐름
    - 인증 흐름 (로그인/회원가입/로그아웃)
  - 페이지 17개 / API 19개 총괄표
