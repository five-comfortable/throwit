## 1. 프로젝트 목표 및 범위 정의

### 1.1 프로젝트 목표

**비전**: 전국 어디서나 대형폐기물 처리를 쉽고 빠르게 해결할 수 있는 통합 모바일 웹 서비스

**핵심 목표**:
1. 전국 17개 시도, 131개 시군구의 대형폐기물 수수료를 한눈에 조회
2. 온라인으로 배출 신청부터 결제까지 원스톱 처리
3. 오프라인 배출 방법(스티커 구매, 주민센터, 운반 대행) 안내 통합 제공
4. 재활용 가능 물품의 역경매 마켓플레이스 운영

**해결하려는 문제**:
| 문제 | 현재 상황 | Thowit 솔루션 |
|------|----------|---------------|
| 수수료 확인 어려움 | 지자체별 사이트를 개별 방문해야 함 | 통합 검색 (22,819건 데이터) |
| 배출 방법 혼란 | 온라인/오프라인 방법이 지역마다 다름 | 지역별 맞춤 안내 |
| 온라인 신청 불편 | 복잡한 기존 시스템 | 4단계 간편 신청 프로세스 |
| 재활용품 처리 | 버리기 아까운 물품의 처리 방법 부족 | 역경매 마켓플레이스 |

### 1.2 프로젝트 범위

**포함 범위 (In Scope)**:
- 대형폐기물 수수료 조회 (공공데이터 기반)
- 온라인 배출 신청 및 결제 UI (PG 연동 제외, UI만 구현)
- 마이페이지 (신청 내역 조회, 영수증 확인)
- 재활용 역경매 (물품 등록/조회/상태 관리)
- 오프라인 배출 안내 (스티커 판매소, 주민센터, 처리시설, 운반 대행)
- 사용자 인증 (회원가입, 로그인)
- 모바일 퍼스트 반응형 웹

**제외 범위 (Out of Scope)**:
- 실제 결제 PG 연동 (Tosspayments 등)
- 네이티브 앱 (iOS/Android)
- 관리자 페이지 (어드민)
- 실시간 알림 (Push, SMS)
- 실제 사진 파일 업로드 (S3 등 스토리지 연동)
- JWT 기반 인증 (현 단계에서는 X-User-Id 헤더 방식)

### 1.3 성공 지표

| 지표 | 목표 |
|------|------|

- 핵심 니즈: 오프라인 배출 방법 안내

### 3.2 F1: 수수료 조회 (핵심 기능)

**개요**: 전국 22,819건의 대형폐기물 수수료 데이터를 지역별로 조회

**입력**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| 시도 | Select | O | 17개 시도 중 선택 |
| 시군구 | Select | O | 선택된 시도의 시군구 목록 |
| 카테고리 | Select | X | 폐기물 구분명 (가구류, 가전류 등) |
| 검색어 | Text | X | 폐기물명 키워드 검색 |

**처리 로직**:
1. 시도 선택 → 해당 시도의 시군구 목록 로드
2. 시군구 선택 → 해당 지역의 카테고리 목록 로드
3. 카테고리 또는 검색어로 품목 필터링
4. 품목 선택 → 수수료 정보 표시
5. **규격이 null인 경우**: 수수료 금액별 자동 매핑
   - 수수료가 여러 개이면 → 오름차순 정렬
   - 라벨: 소형, 중형, 대형, 특대형

**출력**:
| 항목 | 설명 |
|------|------|
| 폐기물명 | 선택된 품목 이름 |
| 규격/크기 | 소형/중형/대형/특대형 또는 실제 규격 |
| 수수료 | 금액 (원) |

**예외 처리**:
| 상황 | 처리 |
|------|------|
| 시도 미선택 | 시군구 Select 비활성화 |
| 검색 결과 없음 | "검색 결과가 없습니다" 메시지 |
| 수수료 데이터 없음 | "수수료 정보가 없습니다" 메시지 |

**관련 API**:
- `GET /api/regions/sido` - 시도 목록
- `GET /api/regions/sigungu?sido={시도}` - 시군구 목록
- `GET /api/waste/categories?sigungu={시군구}` - 카테고리 목록
- `GET /api/waste/items?sigungu={시군구}&category={카테고리}&keyword={검색어}` - 품목 검색
- `GET /api/fees?sido={시도}&sigungu={시군구}&wasteName={폐기물명}` - 수수료 조회

### 3.3 F2: 온라인 배출 신청

**개요**: 4단계 프로세스로 대형폐기물 온라인 배출 신청

**전제 조건**: 로그인 필수 (미로그인 시 로그인 페이지로 이동)

**Step 1: 정보 입력 (ApplyPage)**

| 입력 항목 | 타입 | 필수 | 검증 |
|-----------|------|:----:|------|
| 시도 | Select | O | 17개 시도 목록 |
| 시군구 | Select | O | 해당 시도 시군구 |
| 배출 주소 | Text | O | 상세 주소 입력 |
| 희망 수거일 | DatePicker | O | 오늘 이후 날짜만 선택 가능 |
| 배출 품목 | 품목 추가 | O | 최소 1개 이상 |

**품목 추가 프로세스**:
1. "품목 추가" 버튼 클릭 → 모달 열림
2. 품목 검색 (카테고리 또는 키워드)
3. 품목 선택 → 규격 선택 → 수량 입력
4. 수수료 자동 계산 (수수료 x 수량)
5. 품목 목록에 추가
6. 총 수수료 실시간 합산 표시

**Step 2: 검토 (ReviewPage)**
- 입력된 모든 정보 확인 표시
- 품목별 수수료 상세
- 총 수수료 합계
- "수정하기" → ApplyPage로 돌아감
- "결제하기" → PaymentPage로 이동

**Step 3: 결제 (PaymentPage)**

| 결제 수단 | 설명 |
|-----------|------|
| 카드 결제 | 신용/체크카드 (UI만 구현) |
| 계좌이체 | 무통장입금 (UI만 구현) |

**Step 4: 완료 (CompletePage)**
- 신청번호 표시 (형식: `{지역코드2자}-{YYYYMMDD}-{5자리시퀀스}`)
  - 예: GN-20260221-00001
- "마이페이지에서 확인" 버튼
- "홈으로" 버튼

**상태 흐름**:
```
PENDING_PAYMENT → PAID → COLLECTED
                     ↘ CANCELLED
                     ↘ REFUNDED
```

**예외 처리**:
| 상황 | 처리 |
|------|------|
| 미로그인 | 로그인 페이지로 리다이렉트 |
| 품목 0개 | "품목을 추가해주세요" 알림 |
| 과거 날짜 | DatePicker에서 선택 불가 |
| 서버 에러 | 에러 메시지 표시, 재시도 안내 |

**관련 API**:
- `POST /api/disposals` - 신청 생성
- `POST /api/disposals/{id}/payment` - 결제 처리

### 3.5 F4: 재활용 역경매

**개요**: 재활용 가능한 물품을 등록하고 필요한 사람이 가져갈 수 있는 마켓플레이스

**전제 조건**: 로그인 필수

**물품 등록 입력**:
| 항목 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| 제목 | Text | O | 물품명 |
| 설명 | Textarea | X | 상세 설명 |
| 사진 | File (JSON URL) | X | 최대 5장 |
| 시도 | Select | X | 위치 정보 |
| 시군구 | Select | X | 위치 정보 |
| 주소 | Text | X | 상세 주소 |

**상태 흐름**:
```
AVAILABLE (등록됨) → RESERVED (예약됨) → SOLD (거래 완료)
     ↘ WITHDRAWN (취소됨)
```

**기능**:
| 기능 | 설명 |
|------|------|
| 목록 조회 | 시군구별 필터링 가능 |
| 내 물품 | 내가 등록한 물품만 조회 |
| 상태 변경 | AVAILABLE → RESERVED → SOLD |
| 삭제 | 본인 물품만 삭제 가능 |

**관련 API**:
- `GET /api/recycle/items?sigungu={시군구}` - 목록 조회
- `GET /api/recycle/items/my` - 내 물품
- `POST /api/recycle/items` - 등록
- `PATCH /api/recycle/items/{id}/status?status={상태}` - 상태 변경
- `DELETE /api/recycle/items/{id}` - 삭제

### 3.6 F5: 오프라인 배출 안내

**개요**: 대형폐기물 오프라인 배출에 필요한 시설/업체 정보 제공

**인증 불필요**

**4개 카테고리**:

| 카테고리 | 설명 | 데이터 소스 | 지도 |
|----------|------|-------------|:----:|
| 스티커 판매소 | 대형폐기물 스티커 구매 가능한 편의점/마트 | 샘플 데이터 | O (카카오맵) |
| 주민센터 | 오프라인 배출 신청 가능한 주민센터 | 샘플 데이터 | O (카카오맵) |

### 3.7 F6: 사용자 인증

**개요**: 이메일 기반 회원가입 및 로그인

**회원가입 입력**:
| 항목 | 타입 | 필수 | 검증 |
|------|------|:----:|------|
| 이메일 | Email | O | 이메일 형식, 중복 확인 |
| 비밀번호 | Password | O | 6자 이상 |
| 닉네임 | Text | O | 빈 값 불가 |

**로그인 입력**:
| 항목 | 타입 | 필수 | 검증 |
|------|------|:----:|------|
| 이메일 | Email | O | 이메일 형식 |
| 비밀번호 | Password | O | 빈 값 불가 |

**보안**:
- 패스워드: SHA-256 + 16byte Salt + Base64 인코딩
- 인증 방식: X-User-Id 헤더 기반 (참고 프로젝트 동일)
- 세션 유지: localStorage에 사용자 정보 저장

**인증 필요 기능 vs 비인증 기능**:
| 기능 | 비인증 | 인증 필요 |
|------|:------:|:---------:|
| 수수료 조회 | O | - |
| 오프라인 안내 | O | - |
| 온라인 배출 신청 | - | O |
| 마이페이지 | - | O |
| 재활용 역경매 | - | O |
| 홈페이지 | O | - |

**예외 처리**:
| 상황 | 처리 |
|------|------|
| 중복 이메일 가입 | "이미 사용 중인 이메일입니다" (409) |
| 로그인 실패 | "이메일 또는 비밀번호가 올바르지 않습니다" (400) |
| 인증 필요 페이지 미로그인 접근 | 로그인 페이지로 리다이렉트 |

**관련 API**:
- `POST /api/auth/signup` - 회원가입
- `POST /api/auth/login` - 로그인
- `GET /api/auth/me` - 내 정보 (X-User-Id 헤더 필요)

## 4. 사용자 흐름 (User Flow) 정의

### 4.1 수수료 조회 흐름

```
홈페이지
  │
  ├── [수수료 조회하기] 카드 클릭
  │
  ▼
수수료 조회 페이지 (/fee-check)
  │
  ├── Step 1: 시도 선택 (드롭다운)
  │     └── API: GET /api/regions/sido → 17개 시도 로드
  │
  ├── Step 2: 시군구 선택 (드롭다운)
  │     └── API: GET /api/regions/sigungu?sido={선택된 시도}
  │
  ├── Step 3: 품목 검색
  │     ├── 방법 A: 카테고리 선택
  │     │     └── API: GET /api/waste/categories?sigungu={시군구}
  │     └── 방법 B: 키워드 검색
  │           └── API: GET /api/waste/items?sigungu={시군구}&keyword={검색어}
  │
  ├── Step 4: 품목 선택
  │     └── API: GET /api/fees?sido={시도}&sigungu={시군구}&wasteName={품목}
  │
  └── 결과: 수수료 정보 표시
        ├── 폐기물명, 규격, 수수료 금액
        └── [온라인 배출 신청하기] 버튼 (선택)
              └── → 온라인 배출 신청 흐름으로 이동
```

### 4.2 온라인 배출 신청 흐름

```
홈페이지
  │
  ├── [온라인 배출] 카드 클릭
  │
  ▼
온라인 배출 안내 페이지 (/online)
  │
  ├── 로그인 확인
  │     ├── 미로그인 → 로그인 페이지 (/login) → 돌아옴
  │     └── 로그인됨 → 계속
  │
  ├── [배출 신청하기] 버튼
  │
  ▼
배출 신청 페이지 (/online/apply) ─── ProgressBar: Step 1/4
  │
  ├── 지역 선택 (시도 → 시군구)
  ├── 배출 주소 입력
  ├── 희망 수거일 선택 (오늘 이후)
  ├── 품목 추가 (모달)
  │     ├── 품목 검색
  │     ├── 규격 선택
  │     ├── 수량 입력
  │     └── 수수료 자동 계산
  ├── 품목 목록 표시 (삭제 가능)
  ├── 총 수수료 합계 표시
  │
  ├── [다음] 버튼
  │
  ▼
검토 페이지 (/online/review) ─── ProgressBar: Step 2/4
  │
  ├── 입력 정보 전체 확인
  ├── [수정하기] → /online/apply 로 돌아감
  │
  ├── [결제하기] 버튼
  │     └── API: POST /api/disposals (신청 생성)
  │
  ▼
결제 페이지 (/online/payment) ─── ProgressBar: Step 3/4
  │
  ├── 결제 수단 선택 (카드 / 계좌이체)
  │
  ├── [결제하기] 버튼
  │     └── API: POST /api/disposals/{id}/payment
  │
  ▼
완료 페이지 (/online/complete) ─── ProgressBar: Step 4/4
  │
  ├── 신청번호 표시 (예: GN-20260221-00001)
  ├── [마이페이지에서 확인] → /mypage
  └── [홈으로] → /
```

### 4.3 재활용 역경매 흐름

```
홈페이지
  │
  ├── [재활용 역경매] 카드 클릭
  │
  ▼
재활용 목록 페이지 (/recycle)
  │
  ├── 로그인 확인 (미로그인 → /login)
  │

  │     └── API: GET /api/recycle/items?sigungu={시군구}

  │     └── API: GET /api/recycle/items/my
  │
  ├── 물품 카드 클릭 → 상세 보기
  │     ├── 상태 변경 (AVAILABLE → RESERVED → SOLD)
  │     │     └── API: PATCH /api/recycle/items/{id}/status
  │     └── 삭제
  │           └── API: DELETE /api/recycle/items/{id}

  │
  ▼
물품 등록 페이지 (/recycle/register)
  │
  ├── 제목, 설명, 사진(URL), 위치 정보 입력
  ├── [등록하기] 버튼
  │     └── API: POST /api/recycle/items
  └── 완료 → /recycle 로 이동
```
